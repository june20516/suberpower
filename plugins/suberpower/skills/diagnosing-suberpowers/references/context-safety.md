# 세션 transcript를 위한 context 안전 규칙

transcript 레코드 하나가 1MB를 넘거나 대화 기록 전체를 품고 있을 수 있습니다.
레코드 하나를 통째로 출력하면 진단을 수행하는 세션의 context가 넘칠 수
있습니다. 세션 파일을 읽는 모든 주체는 controller든 subagent든 모든 파일에,
매번, 이 규칙을 따릅니다.

1. **읽기 전에 측정하세요.**

   ```bash
   wc -lc "$F"
   awk '{ if (length($0) > 100000) print NR, length($0) }' "$F"   # long lines
   ```

2. **내용을 보려고 `cat`이나 `grep`을 절대 쓰지 마세요.** 먼저 줄 번호와
   개수를 얻고(`grep -n … | cut -d: -f1`, `jq -r '.type' | sort | uniq -c`),
   그다음 특정 줄에서 작은 필드만 꺼내세요(`sed -n Np | jq -c '{…}'` 또는
   `| cut -c1-500`). 눈앞의 출처에 대해 탐색 단계에서 확립한 필드 추출 명령을
   사용하세요.
3. **500자를 넘는 것은 좁히세요.** 명령 하나가 레코드 하나에 대해 500자 넘게
   반환하면 필드나 범위를 더 좁히세요.
4. **읽기 전용.** 세션 파일을 절대 수정하거나 옮기거나 삭제하지 마세요.
