# 완화 조치 등록부 (Mitigations Registry)

Claude Code harness 버그를 우회하기 위해 이 fork에 추가하는 완화 조치들의 등록부입니다.

업스트림 이슈 상태를 매주 확인하던 자동화(`.github/workflows/upstream-fix-tracker.yml`,
`scripts/check-upstream-fixes.sh`)는 제거되어 현재 **비활성** 상태입니다. 복원하면 다시
동작합니다.

현재 등록된 완화 없음.

| ID | 완화 내용 | 적용 위치 | 업스트림 이슈 | 제거 기준 |
|----|----------|----------|--------------|----------|

## 새 완화 추가 방법

1. 추적 자동화를 복원합니다 (실행 권한도 함께 복원됩니다).

   ```bash
   git checkout e2e0d33 -- scripts/check-upstream-fixes.sh .github/workflows/upstream-fix-tracker.yml
   ```

2. 위 표에 행을 추가합니다. 자동화를 복원한 경우, 스크립트가 **이 파일에서
   `anthropics/claude-code#NNN` 패턴을 읽어** 이슈 상태를 매주 확인하므로 이 파일이 추적
   대상의 단일 소스입니다.
3. 커밋 메시지에 `[M-n]` 태그를 답니다. 새 완화의 ID는 M-5부터 사용하세요 (M-1~M-4는
   종료된 완화에 사용됨).

## 공통 제거 기준

1. 추적 중인 업스트림 이슈가 모두 closed
2. Claude Code를 수정 버전으로 업데이트한 뒤, 해당 완화가 다루던 증상이 2주 동안
   재발하지 않음. 재발하면 사례를 이 파일에 메모로 남겨 관찰 기간을 리셋한다.

## 제거 방법

각 완화의 커밋은 커밋 메시지 앞에 `[M-n]` 태그를 답니다. 한 완화가 여러 커밋일 수
있습니다 (본 구현 + 리뷰 반영 등).

```bash
git log --oneline --grep='\[M-1\]'   # 해당 완화의 커밋 찾기 (여러 개일 수 있음)
git revert <h3> <h2> <h1>            # 최신 커밋부터 역순으로 모두 revert
                                     # (충돌 시 해당 완화의 섹션을 수동 삭제)
```

제거 후: 이 파일에서 해당 행을 삭제하고 `## 종료된 완화`에 한 줄 기록하세요. 남은 행이
없으면 (자동화를 복원한 경우) 추적 워크플로우와 스크립트도 함께 제거한 뒤 plugin 버전을
bump하세요 (M-1~M-4 종료 시 완료됨).

주의사항:
- (자동화를 복원한 경우) 자동 생성된 제거 검토 이슈는 기준 미충족 상태에서 close하지
  마세요 — 제목 중복 검사가 closed 이슈도 포함하므로 한 번 닫으면 재알림이 없습니다.
